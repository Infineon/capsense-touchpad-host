typedef MTB_TOUCHPAD_RET_TYPE(* mtb_touchpad_read_handle_t) (uint16_t subaddress, uint8_t *data, uint16_t length, void *intf_ptr)

Function pointer type for touchpad read operation.

This function pointer defines the interface for reading data from the touchpad device. The implementation should handle communication with the hardware (e.g., I2C) and retrieve data from the specified subaddress.

Parameters
subaddressRegister or memory address within the touchpad device.
dataPointer to buffer where read data will be stored.
lengthNumber of bytes to read.
intf_ptrPointer to interface-specific context or handle.
Returns
Status of the read operation of type MTB_TOUCHPAD_RET_TYPE.
