◆ mtb_touchpad_init()

MTB_TOUCHPAD_RET_TYPE mtb_touchpad_init ( mtb_touchpad_write_handle_t bus_write,
mtb_touchpad_read_handle_t bus_read,
void * intf_ptr,
mtb_touchpad_intf_context_t * context )

Initializes the touchpad interface.

This function initializes CAPSENSE™ Touchpad I2C Host with platform-specific read and write handlers along with the interface context. It sets up the communication layer (e.g., I2C) required for interacting with the touchpad device and stores the configuration in the provided context structure.

Parameters
[in]bus_write: Function pointer to platform-specific write operation.
[in]bus_read: Function pointer to platform-specific read operation.
[in]intf_ptr: Pointer to interface-specific context (e.g., I2C address, bus handle).
[out]context: Pointer to touchpad interface context structure to be initialized.
Returns
MTB_TOUCHPAD_RET_SUCCESS - Initialization successful MTB_TOUCHPAD_RET_INVALID_PARAM - Invalid input parameters MTB_TOUCHPAD_RET_ERROR - Communication or read failure
Note
The function pointers (bus_read and bus_write) must be valid and implemented before calling this function.
The context structure must be allocated by the caller.
This function must be called before performing any touchpad read/write operations.

[in]context: Pointer to initialized touchpad interface context.
Returns
MTB_TOUCHPAD_RET_SUCCESS - Scan mode set successfully MTB_TOUCHPAD_RET_INVALID_PARAM - Invalid input parameters MTB_TOUCHPAD_RET_ERROR - Communication or read/write failure
Note

The 'context' pointer must be a valid, non-NULL pointer.
Any bit outside MTB_TOUCHPAD_SCAN_MODE_IDLE | MTB_TOUCHPAD_SCAN_MODE_ACTIVE (0x03), including MTB_TOUCHPAD_SCAN_MODE_TIMEOUT_ENABLE, makes 'scan_mode' invalid.

◆ mtb_touchpad_get_user_data()

MTB_TOUCHPAD_RET_TYPE mtb_touchpad_get_user_data ( uint8_t * buf,
uint16_t len,
mtb_touchpad_intf_context_t * context )

Retrieves the user data from the touchpad controller.

This function reads up to 'len' bytes from the user data area of the touchpad device into the provided buffer. The location of the user data area is derived from the configured number of sensors. The requested length is validated against the USER_DATA_LEN register before the read is performed.

Parameters
[out]buf: Pointer to buffer where the user data will be stored.
[in]len: Number of bytes to read from the user data area.
[in]context: Pointer to initialized touchpad interface context.
Returns
MTB_TOUCHPAD_RET_SUCCESS - User data retrieved successfully MTB_TOUCHPAD_RET_INVALID_PARAM - Invalid input parameters, or 'len' exceeds the user data area size MTB_TOUCHPAD_RET_ERROR - Communication or read failure
Note
The context must be initialized using mtb_touchpad_init() before calling this function.
The 'buf' pointer must be a valid, non-NULL pointer, and must be at least 'len' bytes.
